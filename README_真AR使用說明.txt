新勢公園 AI 自然偵探｜v2 真 AR 辨識版

這一版與 v1 最大差異：
v1：相機打開後，按一下就播放 AR 圖案，不是真的辨識景點。
v2：使用 MindAR image tracking。手機先分析指定照片，只有鏡頭真的辨識到該景點時，AR 圖騰才會浮出來。

檔案：
index.html       活動首頁
demo.html        示範題：彩色裝置 AR＋扶桑植物辨識
game.html        正式四關＋A/B/C/D 分流
ar_true.html     真 AR 圖像辨識頁
ar_test.html     老師測試三個 AR 目標
style.css
assets/          現場照片

AR 目標：
1. demo  彩色裝置
2. water 水質淨化區水滴裝置
3. river 老街溪河川教育中心

使用方式：
1. 整個資料夾內容上傳 GitHub Repository。
2. Settings → Pages → Deploy from branch → main / root。
3. 等 GitHub Pages 網址生效。
4. 手機開啟 ar_test.html 先測。
5. 第一次開某個 AR 目標，手機會先建立辨識資料，可能數秒到數十秒。
6. 允許相機權限後，把鏡頭對準現場景物。
7. 辨識成功，AR 圖騰才會出現。

重要：
- 這版不需要另外製作 targets.mind，辨識資料會在手機瀏覽器中即時編譯。
- 優點：你可以直接上傳整包，不需要再做編譯檔。
- 缺點：每一支手機第一次開啟每個 AR 關卡時，都要花時間建立辨識資料。
- 正式活動前一定要到新勢公園現場測試三個目標。
- 圖像辨識對平面、紋理豐富、固定不變的景物最穩。老街溪招牌通常會比立體裝置容易辨識。
- 如果現場測試後覺得首次等待太久，下一版可以改成「預先編譯 targets.mind」版本，讓學生直接掃描，速度會更快。

正式分流：
A：水滴 AR → 黃花植物 → 老街溪 AR → 白花植物
B：黃花植物 → 老街溪 AR → 白花植物 → 水滴 AR
C：老街溪 AR → 白花植物 → 水滴 AR → 黃花植物
D：白花植物 → 水滴 AR → 黃花植物 → 老街溪 AR
